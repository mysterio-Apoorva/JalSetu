# Demonstration outline

1. Open JAL-SETU and identify whether the session uses demo or AWS data. Explain the goal: a vehicle location alone does not establish a completed water delivery.
2. Submit a citizen request, inspect the triage priority, and retain the resident OTP privately.
3. Open the dispatcher workspace and show assigned tanker capacity and route stops. In AWS mode, inspect the real workflow and service logs; do not present illustrative benchmark figures as measured results.
4. As the assigned driver, send location, attach a real photo, and enter the resident's code after delivery. Show the resulting evidence hash and remaining route.
5. Demonstrate a rejected invalid attempt and the resulting investigative alert. Do not call a heuristic alert proof of fraud.
6. Show the public aggregated water-equity board and CSV export. Explain that identities and private photo evidence are excluded.

Use a separate newly created request for negative tests. Show the actual AWS account calls if describing the demonstration as live. Do not claim official municipal partnership, optimality, hardware attestation, guaranteed cost savings or zero AWS cost.
