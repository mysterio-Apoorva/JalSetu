  visibility handling, and reduced-motion preferences work independently.

  offscreen, supports manual inspection, and scales to narrow screens.

deployed AWS configuration had been changed. A coordinated release must
include the optimizer code and its geo:CalculateRoute IAM permission, plus the frontend
and updated Amplify custom headers. Existing assignments without stored road geometry
remain explicitly undrawn; newly optimized assignments include provider geometry.

and a confirmed alarm recipient. No data was invented and no emails were sent.
